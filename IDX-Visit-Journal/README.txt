IDX / FIELD NOTES — PROJECT WEBSITE KUNJUNGAN INDUSTRI

CARA MEMAKAI
1. Extract ZIP.
2. VS Code > File > Open Folder > pilih folder IDX-Visit-Journal.
3. Pastikan index.html, css/style.css, dan js/script.js ada.
4. Buka index.html > klik kanan > Open with Live Server.
   Jika belum memasang Live Server, install dari Extensions. Bisa juga buka index.html langsung di browser.

FOTO
Masukkan 10 foto asli ke assets/foto/ dengan nama:
foto-01.jpg sampai foto-10.jpg.
Jika foto PNG, ubah ekstensi src di index.html sesuai nama file PNG.

VIDEO
Masukkan vlog MP4 sekitar 90 detik ke assets/video/ dan beri nama:
vlog-90-detik.mp4
Opsional: tambahkan cover video bernama video-cover.jpg.

PERSONALISASI
Sesuaikan agenda, waktu kegiatan, refleksi, nama, kelas, dan sekolah berdasarkan kegiatan yang benar-benar dilakukan.
Logo IDX di website ini adalah monogram teks dekoratif, bukan file logo resmi BEI.
Profil sejarah BEI: https://www.idx.co.id/id/tentang-bei/ikhtisar-dan-sejarah-bei/
